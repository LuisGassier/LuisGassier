## What I'm building

### [Leaxio](https://leaxio.com) — software for rental businesses

A multi-tenant POS platform for managing inventory, customers, rentals, and payments. Built with Next.js, TypeScript, and Supabase, with role-based permissions and tenant isolation.

`Next.js` `React` `TypeScript` `PostgreSQL` `Supabase`

### [Gravio](https://github.com/LuisGassier/gravio-electron) — desktop software for on-site operations

A Windows application for landfill operations, bringing together weighbridge readings, thermal receipts, and offline workflows with background synchronization.

`Electron` `React` `TypeScript` `Node.js` `Supabase`

### [gssr-toolbelt](https://github.com/LuisGassier/gssr-toolbelt) — reusable skills for coding assistants

A collection of reusable skills and conventions for AI coding assistants, including frontend polish and a template for creating new skills.

`Developer tools` `AI workflows` `Markdown`
